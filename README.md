# Graph1 minifb Demo

This repository renders demos from [graph1 WASM Demo](https://github.com/dipdowel/graph1_wasm_demo) natively, using [minifb](https://github.com/emoon/rust_minifb).
**See:**
- https://graph1.codument.com
- https://github.com/dipdowel/graph1
- https://github.com/dipdowel/graph1_wasm_demo
- - - - - - - - 

**NB:** This project was only tested on Linux with X11.
